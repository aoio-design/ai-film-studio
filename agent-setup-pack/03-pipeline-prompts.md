# Pipeline Prompts — Ready to Paste

*Every prompt below is copy-paste ready. Replace the bracketed parts with
your own details. Use these with your agent in chat, or in the studio review
loop (see studio-ops skill).*

> **House rule that applies to every prompt here:** if an instruction is
> ambiguous — which assets are meant, whether "finished reviewing" means
> "approved, go ahead", which step "generate" refers to — ask the user what
> they mean and WAIT before taking any action. Never guess, never pick a
> reasonable default.

> **Models in these prompts are the default stack.** The selected model for
> each stage is decided live via the model registry — see
> `02-skill-pack/references/model-registry.yaml` + `model-routing.md`. If you
> or the user pick an alternative model for a step, follow the mapping
> protocol there rather than editing these prompts in place.
