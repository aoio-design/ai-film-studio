# Short Comedy Skit Series (Genre Template)

## Overview

How to build a recurring comedy series of 1–2 minute vertical episodes around **one premise and one format**. The worked example below is the **deadpan expert**: a host confidently teaches the audience how to do something, does it catastrophically wrong, then "corrects" it into something worse.

Everything here is a template. The premise, the host, the subject and the episode topics are yours to invent. What this skill locks is the part that makes it a *series* rather than a pile of unrelated clips: **fixed roles** (not fixed names), a fixed beat structure, a cold open rule, running gags with an escalation ladder, and a button that loops back to the top.

**Why the structure travels:** the same skeleton carries a fake tutorial, a mockumentary, a corporate-training parody, a wildlife-documentary parody, a cooking show that goes wrong, or a home-improvement show. Learn it once and change only the premise, the host's fake discipline, and the failure vocabulary.

## When to Use

- Starting a comedy skit series and you need the format locked **before** scripting episode 1
- Writing, reviewing or producing an episode of a running skit series
- Adapting the deadpan-expert format to a new premise (any "expert teaches it wrong" subject)
- Vertical Shorts/Reels/TikTok production planning for scripted comedy
- Auditing whether an existing comedy series is actually a series (recurring cast, running gags, a format) or just a set of standalone gags

## Lock the Format Before Writing Episode 1

Decide these once, write them into the series file, and never re-decide them per episode. An episode that quietly changes one of these reads as a different show.

| Decision | Choose | Why it matters |
|----------|--------|----------------|
| **Format / engine** | e.g. deadpan expert + vignette demos: the host teaches a tip the wrong way, cut to a disastrous demo, then the "right" way (worse) | The engine is the show; the topic rotates, the engine never does |
| **Episode structure** | Self-contained per episode, recurring cast, no serialized arc | Keeps the barrier to entry at zero for a scroll audience |
| **Language** | One language, chosen for reach | Dialogue-driven comedy doesn't survive translation in a 90s cut |
| **Visual style** | Match the look of your other films if you want one brand across the channel | Mixing looks inside a series breaks recognition |
| **Runtime** | 1–2 min per episode (~90–120s) | Long enough for the escalation ladder, short enough for the platform's completion gate |
| **Aspect** | 9:16 vertical | Built for vertical from the start — reframing later costs a generation pass |
| **Season size** | 8–15 topics planned, **pilot first** | A season is a batch decision made after the format proves out on one episode |
| **Deliverable stage** | Scripts first; production planning after the pilot is approved | Words are cheap to change; generated shots are not |

## The Episode Formula (90–120s)

```
COLD OPEN   (0–5s)     Disaster already in progress. TEXT ON SCREEN: "What not to do."
INTRO       (5–15s)    The host addresses camera. Episode topic + "Step one."
ADVICE      (15–28s)   The host states the tip, confidently and absurdly. CUT TO the subject.
DEMO        (28–55s)   The subject follows the advice literally. Catastrophic, comedic failure.
CORRECTION  (55–70s)   The host: "rookie mistake" — plus the "correct" method, which is worse.
PAYOFF      (70–82s)   The correct method triggers a bigger disaster. The subject suffers; the host is oblivious.
TAG         (82–90s)   Sign-off + running gag + loop ending (last frame = first frame).
```

| Beat | Time | What happens | It works when |
|------|------|--------------|---------------|
| **Cold open** | 0–5s | The failure is already happening before anyone explains it | A stranger can tell what went wrong with the sound off |
| **Intro** | 5–15s | Host to camera; topic and "Step one" | Authority is established in one line — no title card, no music sting intro |
| **Advice** | 15–28s | The absurd tip, delivered with bureaucratic gravity | The host is 100% sincere |
| **Demo** | 28–55s | The subject follows it literally; physical, survivable disaster | The joke is visible, not spoken |
| **Correction** | 55–70s | "Rookie mistake" and the *worse* correct method | It escalates; it never repeats the first gag |
| **Payoff** | 70–82s | The correction makes it bigger; subject suffers, host oblivious | The host never breaks character |
| **Tag** | 82–90s | Sign-off line, one running gag, loop back to the cold-open frame | The last frame ≈ the first frame |

**Non-negotiable platform rules:** hook inside the first 2 seconds (never a title card), a hard cut every 3–4 seconds, no static frame over ~4 seconds, burned-in captions on every line, a loop ending for rewatch. Comedy pacing is *faster* than drama — the only shots allowed to sit are locked-wide deadpan beats.

## The Comedy Engine (why the format works)

1. **Authority vs. outcome.** The gap between how confidently the host speaks and what actually happens *is* the joke. Protect that gap: the host must never be in on it.
2. **The correction that is worse.** Escalation, never repetition. "You did it wrong; here's how" must raise the stakes, not reset them.
3. **Literalism.** The recurring outside force (see roles below) follows instructions exactly, with no irony at all. Literal-mindedness is the engine of most of the best bits.
4. **Suffering and obliviousness, split across two characters.** One character absorbs all the physical comedy; the other notices nothing. If both characters react, the joke collapses.
5. **The joke is about the format, not the topic.** Topic-specific jokes land once; format jokes land every episode. A good season topic is one where the *failure* is physical and obvious, not where the subject matter is clever.

## Recurring Characters as Roles (not names)

Write the cast as **functions**. Give each role a fixed look, a fixed voice and one behavioural rule that never changes — then invent names, costumes and designs that suit your premise. Names, looks and voices are yours; the functions are what the format needs.

| Role | Function | Comedy engine | Rules |
|------|----------|---------------|-------|
| **THE HOST** | The expert who teaches it wrong. Anchors every episode. | Total authority, zero self-awareness | Never breaks character, never acknowledges the disaster, never apologises. Dry, flat voice; no shouting; short sentences; no exclamation marks. One fixed costume and one fixed prop (clipboard, badge, pointer) so the audience recognises them in the first frame. A fixed sign-off line every episode. |
| **THE SUBJECT** | The volunteer / trainee / guinea pig who follows the advice and suffers. | All physical comedy; barely speaks | There against their will, resigned, minimal lines, flat weary voice. One costume that visibly marks them as not in charge. Their suffering is cartoonish and survivable. |
| **THE OUTSIDE FORCE** | The recurring antagonist whose literalism drives the plot (a bureaucrat, an inspector, a tourist, a machine, a neighbour, an animal). | Polite, procedural, indifferent — and therefore unstoppable | Never evil, never menacing, never cruel. One fixed design across the whole season with a signature sound. Reads instructions exactly as written. |
| **THE VOICE** *(optional)* | Narrator, announcer, phone menu, intercom | Adds authority or dread with no on-screen body | Audio-only. One voice, fixed, used sparingly. |

**Rules that keep the cast cheap and consistent:**

- Each role gets **one** design, **one** voice and **one** rule. That is the whole character bible a **recurring skit role** needs — the six-field bible in `studio-ops` applies to characters who carry a story, and here you fill only the fields the format depends on (look, voice, one behavioural rule). If the series ever starts carrying plot, fill the rest.
- Recognisability beats depth: the audience should identify a character in a single frame, with the sound off.
- Keep the on-screen speaking cast to two characters per scene — dialogue is spoken by the video model one speaker per clip, and the outside force can always be off-screen or voice-over.
- Roles can be recast in a new series, but **do not transplant a named character, catchphrase or episode idea wholesale from a series you like.** Formats are free to learn from; characters are not.

## Cold Open Rules

The cold open is the first 5 seconds and the most expensive 5 seconds in the episode.

- **Start mid-disaster.** No setup, no "hi guys", no title card. Something has already gone wrong before anyone explains it.
- **One line of on-screen text** orients the viewer: `"What not to do."` That text is the episode's contract with the audience.
- **Mute-proof.** 85% of vertical viewers watch without sound. The failure must be legible from the image alone.
- **Plant the tag.** The image you open on is the image you loop back to in the tag — the last frame should be the first frame, or one beat away from it.
- **Never explain the premise twice.** If the cold open showed it, the intro doesn't re-narrate it; the host just states the topic and moves to step one.

---

## The Button (sign-off and loop)

Every episode ends the same way: the host delivers a fixed sign-off, one running gag fires, and the last frame returns to the cold open.

- **The sign-off is the series' handshake** — the same line, every episode, ideally with the host's name and a claim that has been repeatedly, obviously false. The audience should be able to finish the sentence.
- **No outros.** No "thanks for watching", no subscribe animation, no end card. Any of these breaks the loop and kills the rewatch signal.
- **The loop is a technique, not a bonus.** If the final frame is the opening frame, the platform counts the rewatch, and the episode feels like a joke told twice — which is the correct feeling.
- **One gag per button.** The sign-off, the callback and the loop are enough; three gags stacked in 8 seconds reads as panic.

## Running Gags & Continuity

Running gags are **plants with payoffs**, not repeated jokes. Track them in the series file so they escalate on purpose instead of drifting.

| Stage | What you do | Example shape |
|-------|-------------|---------------|
| **Plant** | Introduce an object, phrase or injury in an early episode, low-key | Episode 1: the subject is handed an ID badge they clearly hate |
| **Escalate** | Bring it back with one more consequence each time | Episode 4: the badge is now framed on the host's wall, in memoriam — the subject is standing right there |
| **Pay off** | Make it the topic or the resolution of a later episode, then retire it | Episode 7: the badge is the whole plot of the episode; after that it stays as set decoration |

**Rules:**

- One new gag per episode, at most. A season survives on three or four gags, not fifteen.
- Every gag pays off within about three episodes of being planted, or it is decoration — decoration is fine, but don't call it a gag.
- Continuity is cheap here and worth it: same costume, same prop, same seat, same wall. Write it into the series file the moment it appears on screen.
- Don't retire a gag by explaining it. Retire it by making it too small to notice, or too big to repeat.

## Building the Episode Menu (one premise → 10–15 episodes)

Take the premise and ask: *what plausible sub-skills does the host's fake discipline claim to cover?* Each answer is a candidate episode. Then run every candidate through three tests:

1. **Is the failure physical and visible in one shot?** If the joke needs dialogue to land, it's a weaker candidate.
2. **Does it need a new set or new cast?** Prefer topics that reuse the same one or two locations and the same three roles.
3. **Does it use the format, or just the topic?** A topic that could work in any episode of the series is the right kind of topic.

**Generic topic shapes to adapt to your premise** (these are shapes, not a list to copy): the safety drill · the paperwork · the phone call · the dress code · the delivery · the interview · the refund · the inspection · the neighbourhood watch · the hotline · the warranty · the training video.

Put the whole menu in the series file with a status per topic (idea → scripted → approved → produced), so the season's coverage is visible at a glance and nothing gets written twice.

## Scripting Conventions (comedy-specific)

- **Host lines: 15 words or fewer.** Bureaucratic gravity, no exclamation marks, no slang. Numbers spelled out for the text-to-speech voice ("nineteen seventy-three").
- **Subject: minimal lines, all resigned.** The joke is in the action lines — write the physical comedy explicitly, because nothing else carries it.
- **One speaker per clip.** The video model lip-syncs a single speaker in each clip. Keep two speaking characters on screen at most, and put the outside force off-screen or in voice-over when the scene would otherwise need three.
- **Comedy timing cannot be implied.** Text-to-speech and the video model cannot pause comedically. Write the beat into the action line or a parenthetical: `(deadpan, no pause)` · `(he does not react)` · `(beat — the door closes behind him)`.
- **Vignette demos: one or two shots each, rapid cuts.** The literal-mindedness of the outside force is the engine; keep the demo shots short.
- **Every scene carries all four production lines:** `CAMERA` (vertical framing; locked wide for deadpan beats), `SFX`, `TEXT ON SCREEN` (captions and on-screen gags), `DURATION`.
- **Loop endings are mandatory** — the tag reconnects to the cold-open frame, every episode.
- **Banned across the series:** gore, real violence, real brands, real people, political content. The outside force stays bureaucratic and polite, never menacing — it is a comedy antagonist, not a threat.

---

## Sound & Music

- **Underscore:** light, deadpan comedy bed (ukulele/marimba energy) under the whole episode; comedic stings punctuate failures. No lyrics — lyrics fight dialogue in a 90-second cut.
- **Signature sounds:** one sound per outside force (a hum, a beep, a chime) used every single time it appears, plus one cheerful "ding" for protocol or announcement beats. Repetition is the joke.
- **Voice casting:** one fixed voice per role for the whole season. Voice consistency is character recognition — the audience should know who is talking with their eyes off the screen. Two or three voices is a comfortable season; more than that and the cast stops being a cast.

## Studio & Review Flow

- **Pilot first — this is a hard rule.** Write the pilot script alone, get it reviewed and approved, *then* batch the remaining topics. Never write ten episodes against an unapproved format; a format change invalidates every one of them.
- **One project for the season, one file per episode** — series bible (format decisions, cast roles, running-gag ladder, topic menu with status) plus `episode-N-*.md` scripts.
- **In the studio:** the season is one season page, the episode is one project, one shot per script scene, and the script lives in the script pane so the owner reviews the words before anything is generated. Layout, accounts and asset saving: `studio-ops`. An editable shotlist per episode: `promptedit-shotlist-director`.
- **Assets before production:** one character sheet per role (host, subject, outside force) plus the recurring location(s). Generated once, reused every episode — the consistency is the branding.

## Production Notes (for when production starts)

- **Vertical 9:16** needs a generator that does vertical natively, or a deliberate reframe — decide this at production planning, not mid-shoot.
- **Photoreal consistency:** one design per role, one mothership/office/kitchen, one wardrobe. Character sheets exist before the first shot is generated.
- **Shot lengths:** 3–8 seconds, hard cuts between them, one locked-wide deadpan beat allowed per episode.

---

## Pitfalls

1. **Writing the whole season before the pilot is approved** — the format will move, and every written episode moves with it. Pilot, review, then batch.
2. **Drama pacing on a comedy script** — hard cuts every 3–4 seconds; no shot over ~8 seconds except a deliberate locked-wide deadpan beat.
3. **Implied comic timing** — the model cannot pause for a laugh. Write the beat into the action line.
4. **A cast too large for one speaker per clip** — three on-screen talkers in one scene is unshootable; move one to voice-over.
5. **The host breaking character** — the moment the host winks at the joke, the authority gap closes and the format dies.
6. **Letting the outside force become menacing** — it kills the tone, and it invites platform trouble. Polite and procedural is funnier and safer.
7. **Repeating a gag instead of escalating it** — the third time a running gag appears it must cost something new.
8. **Explaining the failure in dialogue** — the audience must *see* the disaster; a character narrating what just happened is a rewrite.
9. **Continuity drift on costume, prop or set** — write it in the series file the first time it appears, or it will change between episodes.
10. **Topics that ignore the format** — if the episode would work identically with a different host and premise, the format is doing nothing and the series is drifting.

## Per-Episode Validation Checklist

- [ ] Disaster visible in the cold open within 5 seconds; no title card anywhere
- [ ] Hook lands inside the first 2 seconds
- [ ] The host's advice is absurd but delivered with total confidence
- [ ] The demo failure is physical, cartoonish and survivable
- [ ] The correction is *worse* than the original advice (escalation, not reset)
- [ ] The host never breaks character or acknowledges the disaster
- [ ] The subject does the suffering; the host stays oblivious
- [ ] At least one running gag planted, escalated or paid off
- [ ] Sign-off line delivered, word for word, as in every other episode
- [ ] Final frame loops back to the cold-open frame
- [ ] Two speaking characters at most in any one scene
- [ ] Burned-in captions on every line; hard cut every 3–4 seconds
- [ ] No gore, real violence, real brands, real people or political content
- [ ] Runtime inside 90–120 seconds, 9:16 vertical
